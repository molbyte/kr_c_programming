# 1. 编译

在UNIX操作系统中，首先要在某个文件中**建立这个源程序**，并以`.c`作为文件的**扩展名**。然后通过以下命令进行编译操作：

```c
cc hello.c
```

如果源程序没有错误，编译过程将顺利进行并生成一个可执行文件`a.out`，然后在命令行中输入`a.out`，就能得到相应的信息输出。

## 1.1 a.out

`a.out`本质上是**编译器默认生成的可执行文件名**。

每次执行`gcc xxx.c`的时候，只要没有`-o`参数，就会覆盖原来的`a.out`。

不过实际开发的操作是使用参数指定输出文件名：

```bash
gcc hello.c -o hello
```

# 2. C语言程序组成

一个C语言程序，无论其大小如何，都是由**函数和变量**组成。

其中函数包含一些**语句**，用来指定所要执行的计算操作，变量则用于存储计算过程中使用的值。

## 2.1 函数间的数据交换

>函数之间进行数据交换的一种方法是**调用函数向被调用函数提供一个值（参数）列表**。

也就是说，一个函数想把数据给另一个函数，就在调用它的时候，把数据作为“参数”传进去。

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int result = add(3, 5);
    printf("%d\n", result);
    return o;
}
```

这里的话main是调用函数，add是被调用函数，`3, 5`则是提供的值。

在这个例子中实际发生的就是：**调用函数（main）把 3 和 5 交给了add，而add用 a 和 b 接收。**

的的确确是我们自己写了 3 和 5 ，但是在运行机制中应该是 **main 在调用add时把3和5传进去了**。

参数（列表）就是函数名后面的一对圆括号括起来的东西，双引号括起来的字符序列被称为`字符串（常量）`，目前仅使用它作为printf以及其他函数的参数。

## 2.2 换行

```c
printf("hello, world
")  
```

字符串在此时强行换行了，没有正确结束。

在C里，字符串必须写在一对`""`里面，而且**不能直接跨行**。

printf函数永远不会自动换行，所以也可以**多次调用函数分阶段得到一个长的输出行**。

```c
#include <stdio.h>

int main()

{
    printf("hello, world\n");
}
```

```c
#include <stdio.h>

int main()

{
    printf("hello, ");
    printg("world");
    printf("\n");
}
```

可以使用转义字符（为无法输出或不可见的字符提供了一种可扩充机制）：`\n`

Python支持三引号多行字符串，但是普通字符串也不能直接换行。

```python
message_a = 'Hello World'  # 这是普通字符串，同样不能跨物理行书写

message_b = 'Hello\nWorld'
```

```python
message = """Hello
World"""

print(message)  # 此时就会输出跨行的信息，这就是三引号字符串允许直接在源代码中换行
                # 对于编写多行文本较为方便
                
note = '''Hello
    World'''  # 输出时前面也会保留四个空格，因为python会把三引号内部的换行和空格作为字符串内容的一部分
```

三引号还有一个重要用途是**编写文档字符串**：

```python
def add(a, b):
    """计算两个数字的和，并返回结果。"""
    return a + b
    
print(add.__doc__)
```

文档字符串常用于解释模块、类和函数的用途，方便其他开发者理解代码。

需要注意，三引号本身并不代表注释。它定义的仍然是字符串，只是在函数、类或模块的特定位置使用时，可以成为文档字符串。
