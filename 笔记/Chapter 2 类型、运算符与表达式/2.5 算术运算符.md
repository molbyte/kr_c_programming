
| **运算符** | **含义** | **示例**  | **结果** |
| ------- | ------ | ------- | ------ |
| `+`     | 加法     | `3 + 2` | `5`    |
| `-`     | 减法     | `3 - 2` | `1`    |
| `*`     | 乘法     | `3 * 2` | `6`    |
| `/`     | 除法     | `6 / 2` | `3`    |
| `%`     | 取模/取余  | `7 % 3` | `1`    |
所谓算术运算符就是用来进行数学运算的符号，以上是二元算术运算符（即该运算符需要**两个操作数**才能完成运算）

有关取模运算符`%`特别有用：

```c
10 % 2  // 判断一个数字是不是偶数，结果为0就是没有余数，即为偶数
```


# 1. 整数除法会截断结果中的小数部分

```c
7 / 2  // 结果为 3 ，直接截断处理，不是四舍五入。

// 8 / 3 = 2.666... -> 2
```

但是如果操作数中出现了**浮点数**：

```c
7.0 / 2  // 这里的 7.0 已经不是整数，而是浮点数，所以结果 -> 3.5
```

容易踩坑的是：

```c
int a = 1 / 2;  // 在进行初始化定义赋值之前，就已经进行了整数除法，结果为0
```

而要解决就只需要**让参与运算的至少一个操作数变成浮点数即可**。但是还需注意的是：

```c
int a = 1.0 / 2;  // 这里虽然得到了 0.5 ，但是最后赋值给 `int a`的时候又会发生一次浮点数到整数的转换，同样截断处理，所以最终结果还是赋值为 0 

// 正确写法
double a = 1.0 / 2;
```

# 2. 取模运算符`%`不能用于`float`和`double`

`%` 在 C 语言中是专门用于**整数类型**的。`7.0 % 3.0`是不允许的，需要计算浮点数的“余数”，通常要使用专门的数学函数，而不是 `%`。

# 3. 在有负操作数的情况下，整数除法截取的方向以及取模运算结果的符号取决于具体机器的实现……

```c
-7 / 2  // 数学上即 -7 ÷ 2 = -3.5 ，向 0 截断取 -3 。
7 / 2 = 3 …… 1  // 7 % 2 = 1 , -7 = (-3) × 2 + (-1) , -7 % 2  → -1
```

# 4. 运算符优先级

二元运算符 `+` 和 `-` 具有相同的优先级，它们的优先级比运算符 `*`、`/` 和 `%` 的优先级低……

```
高
↑
│   一元 +、-
│
│   *、/、%
│
│   二元 +、-
│
低
```

```
-5, +5  // 这里的符号不是加减两个数，可以理解为“对5进行符号运算，只需要一个操作数”
```

如果多个运算符优先级相同，就按照从左到右的顺序计算。
