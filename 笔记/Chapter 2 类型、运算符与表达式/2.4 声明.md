>所有**变量**必须**先声明，后使用**。

关于kr中提到的

>某些变量通过上下文进行隐式声明。

是在讲某些特定情况下，例如早期C语言允许：

```c
int main()
{
    printf("hello");
}
	// 如果没有提前声明`printf`，早期C编译器可能会根据调用`printf("hello");`隐式地认为存在一个函数`printf`  
```

但是关于这个**隐式函数声明机制**在现代C标准里已经被废除了，如果没有`#include <stdio.h>`，通常会得到“函数未声明”的警告错误。

一个声明指定一种变量类型，后面所带的变量表可以包含**一个或多个该类型的变量**。一个声明语句中的多个变量可以拆开再多个声明语句中声明。

```c
// 合并声明
int lower, upper, step;
char c, line[1000];

// 单独声明，主要是便于向各声明语句中添加注释
int lower;
int upper;
int step;

char c;
char line[1000];
```

可以在声明的同时对变量进行**初始化**：

```c
int i = 0;
float eps = 1.0e - 5;  // 变量名后紧跟 1. 等号 2. 表达式 -> 变量初始化表达式
```

# 1. 自动变量有关

```c
void test()
{
    int age = 18;
    
    printf("%d\n",age);
}

// 此处的`age`是一个自动变量，简单理解为进入这个代码块时创建，离开这个代码块，生命周期结束。
// 当`test()`被调用时
// 进入 test()
// ↓
// 创建 age
// ↓
// age = 18
// ↓
// 执行函数
// ↓
// 离开 test()
// ↓
// age 生命周期结束
```

如果变量不是自动变量，例如静态变量等非自动变量，则只能进行**一次初始化操作，通常是在程序开始执行之前**，

```c
void test()
{
    static int count = 0;  // 第一次执行时创建并初始化，以后再次进入，不重新创建、初始化

    count++;
    printf("%d\n", count);  // 每次不会初始化为0再行调用
}

test();  // 1
test();  // 2
test();  // 3

// 和自动变量对比一下
void test()
{
    int count = 0;

    count++;
    printf("%d\n", count);
}

test();  // 1
test();  // 1
test();  // 1
```

但是不能笼统理解为这类变量只能修改一次：

```c
static int count = 0;

count = 100;
count = 200;
count = 300;  // 这后面得修改属于赋值，可以发生很多次！初始化动作只发生一次
```

时间上，这类静态变量在正式执行main之前，就已经完成初始化了：

```c
int count = 10;

int main()
{
    printf("%d", count);
}

// 程序启动
// ↓
// 初始化 count = 10
// ↓
// 进入 main()
// ↓
// printf()

// 初始化表达式必须是常量表达式，即**编译器在编译程序的时候，就能够确定结果的表达式。**

int x = 10;
int y = x + 5;  // 通常不能作为静态存储期对象的这种初始化表达式，因为 `x` 是一个变量，不是编译期常量。

int get_number(void)
{
    return 10;
}

static int x = get_number();  // **运行时函数调用**
```


## 1.1 每次进入代码块时，显式初始化自动变量都将被初始化一次，其初始化表达式可以是任何表达式

自动变量的初始化，可以使用运行时才能得到的值：

```c
int get_number()
{
    return 100;
}

void test()
{
    int x = get_number();
}
```

而为什么静态变量不行，是因为**自动变量是在程序运行过程中创建和初始化的；静态变量在程序开始执行时就必须已经准备好。**

简单阐述两个：

```c
void test(int n)
{
    static int x = n + 10;
}

test(20);
test(50);
// 1. 第一次调用得到30，但是第二次调用，就无法重新初始化了，不然就不是静态变量了

static int x = get_number();
// 2. 从概念上来讲，这个表达式是一个函数，而函数调用本身就是需要程序运行起来以后才能发生，但静态变量要求在程序正式执行之前就要确定初始值，所以直接就冲突了。
```

---

默认情况下，外部变量与静态变量都将被初始化为0：

```c
int age;  // 外部变量（全局变量），自动初始化为0

int main()
{
    printf("%d, age");
}

---

int main()
{
    static int count;  // 同样被初始化为0

    printf("%d", count);
}

int main()
{
    int age;  // 未经显式初始化的自动变量，为未定义值（无效值）

    printf("%d", age);
}
```

任何变量声明都可以使用`const`限定符限定。

对数组而言，该限定符指定数组所有元素的值都不能被修改，也可配合数组参数使用，表明函数不能修改数组元素的值，如果试图修改限定符所限定的值，其结果取决于具体的实现。

```c
// 普通数组
int numbers[5] = {1, 2, 3, 4, 5};  // 这个数组的每一个元素都可以修改

numbers[0] = 100;

// 加上`const`
const int numbers[5] = {1, 2, 3, 4, 5};  // 这个数组里的元素都不能通过这个数组名被修改，但是依然可以被读取、参与运算
```
